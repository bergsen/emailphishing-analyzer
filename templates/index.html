Pilih Metode Input:

Panduan Penggunaan

Cara Mendapatkan File .eml

  1. Buka email yang ingin dianalisis melalui browser.
  2. Klik ikon titik tiga vertikal (Lainnya) di pojok kanan atas email tersebut.
  3. Pilih menu "Download message" (Unduh pesan).
  4. File dengan ekstensi .eml akan terunduh otomatis ke komputer.
  5. Klik tombol Choose File di aplikasi ini dan pilih file tersebut.

Cara Menyimpan PDF dari HP

  1. Buka aplikasi email (seperti Gmail) di Handphone Anda.
  2. Buka pesan emailnya, lalu ketuk ikon titik tiga.
  3. Pilih opsi "Print" atau Cetak.
  4. Pada pilihan printer di bagian atas, ubah menjadi "Save as PDF".
  5. Simpan file tersebut ke memori internal HP Anda.
  6. Unggah file .pdf tersebut melalui form di aplikasi ini.

Cara Mendapatkan Raw Teks Email

  1. Buka pesan email melalui browser.
  2. Klik ikon titik tiga vertikal di sebelah tombol balas.
  3. Pilih opsi "Show original" (Tampilkan pesan asli).
  4. Browser akan membuka tab baru berisi baris kode. Klik tombol "Copy to clipboard".
  5. Kembali ke aplikasi ini, lalu Paste (Ctrl+V) teks tersebut ke dalam kotak teks yang tersedia.

Cara Copy-Paste Pesan & Header Manual

  1. Buka pesan email di perangkat Anda.
  2. Klik tahan dan blok teks mulai dari informasi header pengirim (Dari, Kepada, Tanggal, Subjek).
  3. Tarik terus kursor/blokan Anda hingga mencakup seluruh isi (body) pesan email tersebut.
  4. Copy teks yang sudah diblok tersebut.
  5. Paste teks tersebut secara langsung ke dalam kotak teks di aplikasi ini.

2 Menghitung IDF (Inverse Document Frequency)

IDF menilai seberapa langka/penting sebuah Term. Term yang muncul di banyak dokumen akan mendapat nilai kecil, Term langka mendapat nilai besar.

Rumus Dasar IDF IDF(t) = ln( (1 + N) / (1 + DF(t)) ) + 1

Substitusi untuk term yang overlap:
{% for t in ds.overlap_terms %} • {{ t.term }} (muncul di {{ t.df }} dokumen):
  IDF = ln( (1 + {{ ds.total_kb_docs }}) / (1 + {{ t.df }}) ) + 1 = {{ t.idf }}

4 L2-Normalization (Standarisasi Panjang Vektor)

Sebelum menghitung Cosine Similarity, scikit-learn melakukan normalisasi agar email tidak bias pada panjang teks. Setiap nilai mentah (dari Langkah 3) akan dibagi dengan Panjang Vektor (Norm).

A. Menghitung Panjang Vektor (Norm) Rumus panjang vektor:
||V|| = √( x₁² + x₂² + x₃² + ... )

Dokumen A (Email Query):
||A|| = √( {% for t in ds.overlap_terms[:3] %}{{ "%.4f"|format(t.unnorm_tfidf_query) }}² + {% endfor %}... )
||A|| ≈ {{ "%.4f"|format(true_query_norm) }}

Dokumen B (Pola KB {{ tp.id }}):
||B|| = √( {% for t in ds.overlap_terms[:3] %}{{ "%.4f"|format(t.unnorm_tfidf_kb) }}² + {% endfor %}... )
||B|| ≈ {{ "%.4f"|format(true_kb_norm) }}
B. Membagi Nilai per-Term (X_norm = X / ||V||) Dari mana nilai normalisasinya berasal? Kita bagikan nilai mentah TF-IDF dengan Norm yang didapat di atas.

5 Menghitung Cosine Similarity (Dot Product)

Karena vektor sudah dinormalisasi di Langkah 4 (sehingga penyebut rumusnya adalah 1), kita hanya perlu menghitung bagian pembilangnya: Perkalian Dimensi Sejajar (Dot Product) menggunakan nilai vektor yang sudah ternormalisasi.

Cosine Similarity = Σ ( VektorA_Norm × VektorB_Norm )
A. Menghitung Dot Product (Khusus Term Overlap) Term yang tidak ada di salah satu dokumen akan dikalikan dengan nol (0) dan hangus.

{% for t in ds.overlap_terms %} {{ t.term }}: {{ "%.4f"|format(t.norm_tfidf_query) }} × {{ "%.4f"|format(t.norm_tfidf_kb) }} = {{ "%.6f"|format(t.product) }} (Overlap)
{% endfor %} [Term non-overlap]: Nilai_A × 0 = 0

Total Dot Product (A · B) = {{ "%.6f"|format(ds.dot_product) }}
B. Hasil Akhir (Skor Kesamaan) Cosine Similarity = {{ "%.6f"|format(ds.dot_product) }} / ( 1.0000 × 1.0000 )

Cosine Similarity ≈ {{ "%.4f"|format(ds.cosine_similarity) }}
